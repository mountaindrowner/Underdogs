# 05 — Art Direction

*How to make ~120 cards look like one game. Every card in `docs/04-card-database.md` already has a 🎨 seed line (subject · pose · setting · mood). This doc gives the shared wrapper so the whole set is consistent when you batch-generate.*

---

## Master style prompt (prepend to every card's 🎨 seed)

> *Illuminated-manuscript-meets-modern-epic trading-card illustration. Painterly digital art with gold-leaf accents on a parchment-and-ink palette; deep cinematic shadow, warm directional light, rich texture. Grounded and reverent — historically-plausible ancient Near-Eastern / first-century dress and setting. Single dramatic focal figure or moment, mid-shot, dynamic but dignified. **No cartoon halos, no kitsch, no modern objects, no visible face of God, no gore.** Muted earthy base with one saturated signature color. Card-portrait framing, room at edges for a frame overlay.*

Then append the card's 🎨 line and its **class signature color** (below). Keep a fixed aspect ratio for all portraits (recommend **4:3 landscape crop** for the card window; a taller **splash** version for Fulfill transformation moments).

## Per-class signature palette
| Class | Signature color | Feel |
|---|---|---|
| 🕮 Prophet | storm-blue & fire-orange | tension, revelation, judgment |
| ⚔ Warrior | bronze & scarlet | heat, dust, valor |
| ✚ Priest | white-gold & incense-blue | hush, holiness, mercy |
| 🐑 Shepherd | dawn-green & wool-cream | pastoral calm, care |
| ⭑ Patriarch | starfield-indigo & desert-tan | vastness, promise, night sky |
| 🔥 Disciple | flame-red & amber | warmth, spread, upper-room glow |

## Consistency techniques (for whatever generator you use)
- **One character sheet per recurring hero first** (front / 3-4 / action pose), then generate that hero's card art referencing the sheet — this is what keeps the three Davids feeling like the same person aged/changed across classes.
- Lock a **seed / style reference image** per class so all cards in a class share lighting and texture.
- Generate the **Fulfilled form** as a deliberate visual echo of the early form (same face, elevated: David boy → David crowned; Simon soaked → Peter solid).
- Keep villains (Adversary pool) a shade colder and more ornate than the faithful — never comic, but clearly *other*.

## Card frame spec (matches the prototype)
- Parchment body, gold-dark border. Cost gem **top-left** (blue diamond). Attack gem **bottom-left** (gold), Health gem **bottom-right** (red) — minions only.
- Name plate across the middle; rules text below; a small **rarity dot** (grey/blue/purple/orange) under the name.
- Faint **era-tag sigil** watermark behind the text (Genesis/Exodus/Judges/Kingdom/Exile/Apostles) so a card's tribe reads at a glance.
- Class is read from the card's home deck / border treatment (assign a per-class border accent using the palette above).

## Generation pipeline (build-time, via the Gemini image API)

Card art is generated by a **build tool** in `/tools`, never at game runtime. Recommended model: **Google's Gemini image API (Nano Banana / Gemini 2.5-Flash-Image family)** — chosen for best-in-class **character consistency** (feed reference images to keep the same hero recognizable across cards) and cost (Google AI Studio free tier ~500 images/day; ~$0.03–0.04/image paid; batch API ~half). Requires only a free Google AI Studio API key — **no subscription**. (A ChatGPT/OpenAI subscription does not grant API access and OpenAI's models are weaker at character consistency, so not recommended here.)

**Workflow:**
1. **Character sheets first.** For each recurring hero, generate a reference sheet (front / 3-4 / action) and save it in `/ui/assets/refs/<hero>.png`.
2. **Batch script** iterates the card database: for each card, build the prompt = `master style prompt` + card `art` line + class signature color; attach the relevant hero reference image(s) for consistency; call the API; save to `/ui/assets/cards/<card_id>.png`.
3. **Fulfilled forms** reference the early form's output as an input image, so the transformation reads as the same person elevated.
4. Keep a fixed aspect ratio; request the card-window crop and (optionally) a taller splash for Fulfill moments.
5. Review, re-roll misses individually, keep a seed/ref per class so a whole class shares lighting/texture.

Store keys in `.env` (git-ignored). The script is idempotent — skip cards whose PNG already exists unless `--force`.

## Rarity frame spec (frame-only style layer)

Rarity changes **how the card looks, never the art and never the stats.** The illustration is the illustration; rarity is communicated by *frame decoration*. Implemented as a swappable style layer in the card compositor — the art window, stats, cost gem, and name banner stay identical in size and position across all rarities; only the accents below change.

**Rarity gem (required, primary signal)** — the dot under the name, next to the era tag:
| Rarity | Gem | Escalating frame treatment |
|---|---|---|
| **Common** | white/grey | Plain baseline frame. Nothing extra. |
| **Rare** | blue | Blue rarity gem-glow + a thin blue secondary trim line in the gold border + faint blue glow hugging the art window. |
| **Epic** | purple | Purple accent, stronger — trim line + art/banner glow more pronounced. |
| **Legendary** | orange/gold | Gold-heavy: gold trim + gold art/banner glow + a **name-banner flourish** (a small gold crown/laurel flanking the title). David the King should *look* legendary before you read a word. |

**Two lines we hold (echoing the Laws & CLAUDE.md §7):**
1. **Never gate art quality by rarity.** A Common's illustration is generated with the exact same style prompt, reference-consistency pass, and re-roll budget as a Legendary's — only the *frame* is fancier. Cheap-looking commons make a game feel cheap.
2. **Rarity ≠ power.** The fancy gold frame signals "collectible chase / build-around," not "stronger card." A free starter deck must be able to beat an all-Legendary deck.

*Optional in-game touch:* a very subtle animated **light-sweep shimmer on Legendary frames only** (CSS `@keyframes` gold gradient sweep, ~4–6s loop, `prefers-reduced-motion`-gated). Makes legendaries feel special on the board without touching the art. Reverent at the sacred core — hush the holy (Law 5).

## Do-not list (art-specific echo of the Laws)
- Never depict God the Father or Jesus' face. Divine presence = light, cloud, fire, off-frame radiance.
- No blood, wounds-in-detail, or death agony. Defeat = falling, fading to light/dust.
- No haloed-saint cheese, no glowing crosses as decoration, no modern anachronisms.
- Keep women heroes dignified and active (Deborah judging, Jael's understated menace, Esther's resolve) — never decorative.
