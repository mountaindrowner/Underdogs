# 22 — The Codex: UNDERDOGS' UI design language

*Why the menus look the way they do, and the rules for keeping them that way. Decided in D-47.*

## The problem this solves

Before this, the interface was a generic web kit painted brown: the same rounded rectangle with a 1px gold border and a brown gradient on every surface, pill buttons, glass orbs, emoji class icons (📜🛡️✨🐑⭐🔥), and Cinzel small caps everywhere. It read as AI-designed because nothing in it came from the game's own fiction.

The reference games all start from **one governing metaphor** and build every UI element out of it:

- **Hearthstone:** the interface *is* a physical object (the box). Every button is a lever, crystal, or toy.
- **Legends of Runeterra:** restrained chrome, and a strict system of region crests and colours.
- **Yu-Gi-Oh! Master Duel:** the anime's holographic duel-disk tech, from panels to cut-ins.

## The metaphor

**UNDERDOGS is a book.** The menus are leaves of a codex, the battle is played on the table the book rests on, and opening a match is turning a page.

This fits the tone rule exactly: *epic on the board, funny in the margins.* Medieval scribes literally drew jokes in the margins (snails jousting knights), so the humour gets a real home. On the main menu, "giants sold separately" sits in the margin with a manicule pointing at it.

## The materials (and only these)

| Material | Token | Use |
|---|---|---|
| Vellum | `--vellum` + procedural grain/foxing | every menu surface (`.vellum`, `.leaf`) |
| Iron-gall ink | `--ink`, `--ink-2`, `--ink-3` | text, rules, borders |
| Rubric (vermilion) | `--rubric` | numerals, kickers, chosen state, the ribbon |
| Gold leaf | `--gilt` (hammered gradient) | primary buttons, crest/initial frames, rules |
| Pigments | lapis, azurite, verdigris, murex, umber, ochre | crest fields, initials, rarity tints |

**Never:** glass, neon, glossy gradients, pill shapes, emoji, or rounded corners over ~3px.

## Type

| Role | Face | Licence |
|---|---|---|
| Headings, buttons, labels | **IM Fell English SC** (Fell SC) | OFL |
| Body, subtitles, marginalia | **IM Fell English** (roman + italic) | OFL |
| Illuminated initials only | **Uncial Antiqua** (insular uncial, Book of Kells) | OFL |

The IM Fell faces are 1670s printing types, so they feel bookish without being costume-y. Card faces keep their own type; the card-fit pass (D-44) was calibrated on it.

## The kit (`ui/src/codex/`)

| Piece | What it is |
|---|---|
| `Folio` | the shared frame for every sub-screen: scene behind, one ruled vellum leaf, the ribbon back, an illuminated title |
| `Rubric` / `DropCap` | a title opened by an Uncial initial in a gilt pigment square |
| `Crest` | a game-icons glyph in gold on a class-pigment field, in a gilt frame (replaces emoji) |
| `Glyph` | any of the bundled icons, drawn in `currentColor` |
| `Rule` | gold divider with a centred lozenge |
| `Corners` | the four gilt corner fleurons of a ruled page |
| `codex.css` | tokens + every menu component style. **Loaded last** so it governs. |
| `glyphs.ts` | generated by `ui/scripts/gen-glyphs.mjs`; only the icons we use ship |

## Patterns

- **Navigation:** a silk **ribbon bookmark** hanging over the top edge ("‹ Contents"). Never a pill "back" chip.
- **Selection:** a red **manicule** (☞) in the margin points at the chosen entry; chosen ledger marks fill with rubric.
- **Hierarchy through ornament:** more ornament means more important. A gilt plaque is a primary action; an inked frame is secondary; a ledger mark is a filter.
- **Lists are ledgers:** ruled lines, rubric numerals, dotted leaders (the Contents, deck lists, Daily Bread).
- **The album:** unowned cards render as faded sepia sketches, like an unfilled album page.
- **Two surfaces:** vellum (menus: ink on light) and the table (battle: light on dark). Components carry a variant for each, e.g. quiet buttons become gilt-edged slips on the table.

## Resources used

- **Fonts:** IM Fell English / English SC (Igino Marini) and Uncial Antiqua (Astigmatic), via Fontsource, SIL OFL 1.1. The latin subsets are bundled in `ui/assets/fonts/` with their licences.
- **Icons:** [game-icons.net](https://game-icons.net) (Lorc, Delapouite & contributors), CC BY 3.0, via the `@iconify-json/game-icons` dev dependency. Credited in `CREDITS.md` and on the Settings screen.
- **Pigment palette:** historical manuscript pigments (vermilion, azurite, lapis/ultramarine, verdigris, orpiment, leaf gold), per the Royal Society's summary of English manuscript pigment research.
- **Technique:** procedural vellum grain/foxing as SVG `feTurbulence` data URIs (no texture files); `border-image` gilt frames; chamfered plaques via `clip-path`.

## The table (battle chrome, D-48)

The battle board is the table the book rests on, so its chrome uses the book's materials on a dark surface:

| Element | Treatment |
|---|---|
| Hero portraits | illuminated roundels in a gilt ring (yours gold, the rival's vermilion) |
| Health | a disc of red sealing wax with the number pressed in |
| End Turn | a wax seal you press; it tilts on hover and pulses gold when you've nothing left to do |
| Hero power | an illuminated medallion: your class glyph in gold on lapis |
| Turn banner | a vellum strip with swallowtail ends: "Dawn 3 — your turn" |
| Victory / defeat | the same strip, larger; defeat is inked in rubric |
| Foresee / Discover | a vellum leaf laid over the table, opened by an initial |
| Tooltips + glossary | slips of vellum in iron-gall ink |
| Match start | the book's leather boards close with a tooled gold frame and the title in gold, then swing open |
| Relics | lapis hexagons with a gilt edge |

**Numbers** on game pieces (health, costs, deck counts) use Cinzel's lining figures (`--f-num`). IM Fell's old-style figures make "30" read as "3o" on a small badge.

## Adding a new screen

1. Wrap it in `<Folio scene title kicker back>`. Don't build your own top bar.
2. Use `.deckTile`-style entries, `.chip` ledger marks, `.bigbtn` / `.bigbtn.quiet`, and `Crest`/`Glyph`. No emoji.
3. Screenshot it at 1280×720 and 844×390 before calling it done.
